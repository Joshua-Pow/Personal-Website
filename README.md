This is a Vite + [TanStack Start](https://tanstack.com/start) personal site, linted with [Ultracite](https://www.ultracite.ai) (Oxlint + Oxfmt) and deployed to Cloudflare Workers.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `npm run lint` — Ultracite check + TypeScript
- `npm run fix` — Ultracite auto-fix
- `npm run build` — production build
- `npm run deploy` — sync adage images and deploy with Wrangler
